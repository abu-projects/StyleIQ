# SIQ-046 — Simplify Not for Me feedback

## Ticket

- ID: SIQ-046
- Comment: Simplify Not for Me feedback
- Scope: Specific Screen
- Screen / Product Area: Outfit Feedback
- Size: Medium
- Workstream: Outfit Actions & Saved Looks
- Original Description: Open a quick feedback sheet with options such as Too Formal, Too Casual, Wrong Color, Don't Like This Item, Not My Style, or Other, then return immediately to the outfit.

## Problem

The current `0.html` prototype exposes this area through E-03 negative feedback converted to a local sheet on the outfit. The relevant rendering/routing surface is `screens registry, renderScreen, go, actionScreen`.

Current behavior is partially represented, but the ticket acceptance is not proven end to end. The existing architecture still exposes feature-oriented routes and, where applicable, separate configuration, processing, or result states. No dedicated `0.html` regression evidence currently closes SIQ-046.

## UX Decision

- Replace the standalone negative-feedback journey with a quick bottom sheet.
- Provide concise reasons: Too Formal, Too Casual, Wrong Color, Don't Like This Item, Not My Style, Other.
- Submit instantly and return to the outfit.
- Allow optional text only behind Other / Tell Muse more.

The decision must preserve the existing editorial/liquid-material direction, reduce decisions and nested screens, and reuse canonical state rather than creating a parallel feature.

## Current Flow

`D-04/G-02 → separate E/G subroutes for save, feedback, sharing, metadata, visibility, and delete.`

## Target Flow

`Current context → Simplify Not for Me feedback → immediate useful result or primary action → optional edit/sheet only when needed.`

Use a full screen only for a distinct user job. Prefer direct action, inline state, one shared bottom sheet, background work, or progressive disclosure for intermediate steps.
