# SIQ-027 — Use swipe, hold, and drag where appropriate

## Ticket

- ID: SIQ-027
- Comment: Use swipe, hold, and drag where appropriate
- Scope: General
- Screen / Product Area: Whole Product
- Size: Medium
- Workstream: Product Simplification Foundation
- Original Description: Introduce lightweight gestures for outfit alternatives, quick item actions, rearranging, and Style Studio interactions while keeping important actions accessible without gestures.

## Problem

The current `0.html` prototype exposes this area through D-04 outfit alternatives, F-01 advanced Studio, G-02 Look actions. The relevant rendering/routing surface is `screens registry, renderScreen, go, homeScreen / mirrorToday / outfitFamilies, studioScreen / mirrorStudioV2, savedScreen`.

Current behavior is partially represented, but the ticket acceptance is not proven end to end. The existing architecture still exposes feature-oriented routes and, where applicable, separate configuration, processing, or result states. No dedicated `0.html` regression evidence currently closes SIQ-027.

## UX Decision

- Add gestures only where they reduce friction: swipe through outfit variations, long-press quick actions, drag/reorder in advanced Studio.
- Always keep an accessible visible alternative for important actions.
- Do not introduce hidden gesture-only behavior for destructive or critical actions.

The decision must preserve the existing editorial/liquid-material direction, reduce decisions and nested screens, and reuse canonical state rather than creating a parallel feature.

## Current Flow

`The screen index exposes the capability through feature-specific routes, often with separate full-screen configuration, processing, and result states.`

## Target Flow

`Current context → Use swipe, hold, and drag where appropriate → immediate useful result or primary action → optional edit/sheet only when needed.`

Use a full screen only for a distinct user job. Prefer direct action, inline state, one shared bottom sheet, background work, or progressive disclosure for intermediate steps.
