## Problem

No dedicated `0.html` regression evidence currently closes SIQ-042.

## UX Decision

- Add an explicit My Looks count to Profile/My Atelier.
- Count canonical looks consistently rather than hard-code a number.
- Make the count link to the user's Looks collection.

The decision must preserve the existing editorial/liquid-material direction, reduce decisions and nested screens, and reuse canonical state rather than creating a parallel feature.
