# SIQ-019 — Ask what StyleIQ should help with

## Ticket

- ID: SIQ-019
- Comment: Ask what StyleIQ should help with
- Scope: Specific Screen
- Screen / Product Area: Onboarding
- Size: Medium
- Workstream: Onboarding
- Original Description: Consider starting personalization around the user's job-to-be-done, such as getting more outfits, planning what to wear, shopping intentionally, packing, or understanding their style.

## Problem

The current `0.html` prototype exposes this area through S-02/A-01 onboarding decision point with D-02/M-01 first destination. The relevant rendering/routing surface is `screens registry, renderScreen, go, onboarding, homeScreen / mirrorToday / outfitFamilies, museScreen / enrichCoreScreens`.

Current behavior is partially represented, but the ticket acceptance is not proven end to end. The existing architecture still exposes feature-oriented routes and, where applicable, separate configuration, processing, or result states. No dedicated `0.html` regression evidence currently closes SIQ-019.

## UX Decision

- Evaluate adding one job-to-be-done question instead of several profile questions.
- Use options focused on user goals: more outfits, planning, intentional shopping, trips, understanding style.
- Use the answer to personalize the first destination or first Muse suggestion, not to create another long branch.
- Keep the question skippable if it does not materially improve the first experience.

The decision must preserve the existing editorial/liquid-material direction, reduce decisions and nested screens, and reuse canonical state rather than creating a parallel feature.

## Current Flow

`S-00 → S-01 → S-02 → A-series setup screens → A-11/D-02 first value.`

## Target Flow

`Current context → Ask what StyleIQ should help with → immediate useful result or primary action → optional edit/sheet only when needed.`

Use a full screen only for a distinct user job. Prefer direct action, inline state, one shared bottom sheet, background work, or progressive disclosure for intermediate steps.
