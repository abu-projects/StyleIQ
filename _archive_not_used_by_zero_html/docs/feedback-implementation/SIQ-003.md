# SIQ-003 — Add Learn from My Photos

## Ticket

- ID: SIQ-003
- Comment: Add Learn from My Photos
- Scope: General
- Screen / Product Area: Closet / Style Learning
- Size: Large
- Workstream: Closet & Photo Import
- Original Description: Allow users to provide personal outfit photos or historical photos so StyleIQ can learn their style, repeated pieces, combinations, colors, and preferences.

## Problem

The current `0.html` prototype exposes this area through B-01/B-02 shared photo ingestion; NEW learning review state surfaced from L-01 Profile and M-01 Muse. The relevant rendering/routing surface is `screens registry, renderScreen, go, importScreen / mirrorItemUpload, profileScreen / mirrorProfile, museScreen / enrichCoreScreens`.

Current behavior is partially represented, but the ticket acceptance is not proven end to end. The existing architecture still exposes feature-oriented routes and, where applicable, separate configuration, processing, or result states. No dedicated `0.html` regression evidence currently closes SIQ-003.

## UX Decision

- Create a visual-learning entry that lets the user select historical personal outfit photos.
- Use the photos as Style Intelligence input: repeated garments, combinations, silhouettes, colors, and recurring outfit formulas.
- Keep inferred learning editable/undoable and clearly distinguish inferred information from confirmed Closet items.
- Reuse the same ingestion foundation as batch Closet photo import where possible.

The decision must preserve the existing editorial/liquid-material direction, reduce decisions and nested screens, and reuse canonical state rather than creating a parallel feature.
