# SIQ-061 — Reduce emphasis on abstract scores

## Ticket

- ID: SIQ-061
- Comment: Reduce emphasis on abstract scores
- Scope: General
- Screen / Product Area: Analytics
- Size: Medium
- Workstream: Weekly Recap & Analytics
- Original Description: Avoid making Style Score or Closet readiness the main goal. Prioritize actionable information such as wears, cost per wear, underused pieces, combinations, and useful wardrobe behavior.

## Problem

The current `0.html` prototype exposes this area through I-02 analytics, C-06 intelligence, L-01 Profile, M-03 wardrobe insight. The relevant rendering/routing surface is `screens registry, renderScreen, go, plannerScreen / mirrorPlanner, closetScreen / mirrorCloset, profileScreen / mirrorProfile, museScreen / enrichCoreScreens`.

Current behavior is partially represented, but the ticket acceptance is not proven end to end. The existing architecture still exposes feature-oriented routes and, where applicable, separate configuration, processing, or result states. No dedicated `0.html` regression evidence currently closes SIQ-061.

## UX Decision

- Audit Style Score, Closet readiness, and other gamified metrics.
- De-emphasize or remove them where they act as goals without clear user value.
- Prioritize cost per wear, underused items, most worn, combinations, rediscovery, and useful spending insights.
- Preserve a metric only if it supports a decision.

The decision must preserve the existing editorial/liquid-material direction, reduce decisions and nested screens, and reuse canonical state rather than creating a parallel feature.

## Current Flow

`The screen index exposes the capability through feature-specific routes, often with separate full-screen configuration, processing, and result states.`

## Target Flow

`Current context → Reduce emphasis on abstract scores → immediate useful result or primary action → optional edit/sheet only when needed.`

Use a full screen only for a distinct user job. Prefer direct action, inline state, one shared bottom sheet, background work, or progressive disclosure for intermediate steps.
