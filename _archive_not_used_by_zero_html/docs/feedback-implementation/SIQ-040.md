# SIQ-040 — Add clear Creators & Celebrities management

## Ticket

- ID: SIQ-040
- Comment: Add clear Creators & Celebrities management
- Scope: Specific Screen
- Screen / Product Area: Style Inspiration
- Size: Medium
- Workstream: Style Inspiration, Creators & Profile
- Original Description: Give users an obvious place to add creators or celebrities whose style they follow, including references from Instagram and Pinterest.

## Problem

The current `0.html` prototype exposes this area through NEW management state under L-01 Profile with K-01/K-02 discover/search. The relevant rendering/routing surface is `screens registry, renderScreen, go, profileScreen / mirrorProfile, discoverScreen / mirrorDiscover`.

Current behavior is partially represented, but the ticket acceptance is not proven end to end. The existing architecture still exposes feature-oriented routes and, where applicable, separate configuration, processing, or result states. No dedicated `0.html` regression evidence currently closes SIQ-040.

## UX Decision

- Provide a clear list/input for creator or celebrity references.
- Support names/handles/links as prototype inputs and removable references.
- Keep Instagram/Pinterest connection behavior clearly labeled as simulated unless real integration exists.
- Surface this under Style Inspiration, not as an unrelated settings screen.

The decision must preserve the existing editorial/liquid-material direction, reduce decisions and nested screens, and reuse canonical state rather than creating a parallel feature.

## Current Flow

`L-01/K-01/G-01 expose related content through separate destinations with limited shared attribution/state.`

## Target Flow

`Current context → Add clear Creators & Celebrities management → immediate useful result or primary action → optional edit/sheet only when needed.`

Use a full screen only for a distinct user job. Prefer direct action, inline state, one shared bottom sheet, background work, or progressive disclosure for intermediate steps.
