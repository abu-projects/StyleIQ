# SIQ-069 — Remove the ChatGPT-like visual feeling

## Ticket

- ID: SIQ-069
- Comment: Remove the ChatGPT-like visual feeling
- Scope: General
- Screen / Product Area: Visual Design
- Size: Foundation
- Workstream: Visual System Constraints
- Original Description: Avoid generic AI gradients, excessive glow, colorful generated-looking cards, and predictable AI styling. Keep the product premium, editorial, photographic, restrained, and fashion-focused.

## Problem

The current `0.html` prototype exposes this area through Whole-app final visual audit after all major UX work. The relevant rendering/routing surface is `screens registry, renderScreen, go`.

Current behavior is partially represented, but the ticket acceptance is not proven end to end. The existing architecture still exposes feature-oriented routes and, where applicable, separate configuration, processing, or result states. No dedicated `0.html` regression evidence currently closes SIQ-069.

## UX Decision

- Remove generic AI-product visual cues: loud multi-color gradients, glowing cards, excessive tinting, and repetitive generated-looking decorative surfaces.
- Favor editorial fashion photography, neutral material depth, restrained accents, and clear hierarchy.
- Keep liquid glass subtle rather than turning every card into a colorful glass panel.
- Review the whole app after feature work for consistency.

The decision must preserve the existing editorial/liquid-material direction, reduce decisions and nested screens, and reuse canonical state rather than creating a parallel feature.
