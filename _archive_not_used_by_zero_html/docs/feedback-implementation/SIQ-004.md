- Original Description: Allow users to select multiple existing photos and let StyleIQ identify potential wardrobe items instead of requiring every Closet item to be added manually one by one.

## Problem

The existing architecture still exposes feature-oriented routes and, where applicable, separate configuration, processing, or result states. No dedicated `0.html` regression evidence currently closes SIQ-004.

## UX Decision

- Allow batch selection of existing photos rather than one item at a time.
- Detect candidate garments across the selected photos and deduplicate likely repeated pieces.
- Automatically create high-confidence Closet items and collect uncertain items into one review surface.
- Never force the user through a full confirmation form for every confident item.

The decision must preserve the existing editorial/liquid-material direction, reduce decisions and nested screens, and reuse canonical state rather than creating a parallel feature.
