## UX Decision

- From a photographed product, identify the item and compare it against the user's Closet and preferences.
- Show compatibility, duplicate risk, likely outfit usefulness, and a concise Muse recommendation.
- Use one visual evaluation surface with actions such as Save, Compare Existing, or See Outfit Ideas.
- Do not make the user enter product metadata manually unless detection is uncertain.

The decision must preserve the existing editorial/liquid-material direction, reduce decisions and nested screens, and reuse canonical state rather than creating a parallel feature.
